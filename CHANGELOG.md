# Changelog

This changelog documents published GitHub releases. For subsequent releases, entries reflect the verified differences between each release tag and the immediately preceding published tag. The first published release is described from the tagged source tree.

## 1.2.0 - 2026-11-18

- Reintroduced configurable teacher appointment availability, bookings and waiting lists in the course activity.
- Added appointment reporting, booking/calendar services and related activity completion support.
- Replaced the private academic guidance request workflow introduced in 1.1.0 with appointment scheduling.

**Comparison:** [1.1.1...1.2.0](https://github.com/EduardoKrausME/moodle-mod_officehours/compare/1.1.1...1.2.0)
